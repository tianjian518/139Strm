存储管理
移动云盘（139 / 和彩云）唯一支持的存储
💾 移动云盘
登录网页版后 F12 → 网络 → 任意请求 → 请求头 Authorization，去掉开头的 Basic 空格 后粘贴
留空即可；若使用，需登录 mail.10086.cn 后复制完整 Cookie（含 Os_SSo_Sid 与 RMKEY）
