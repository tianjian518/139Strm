139Strm · 移动云盘 STRM 工具

直连移动云盘，生成 .strm 供 Emby / Jellyfin 入库；播放走 302 直跳云盘，不占本机带宽

1. 连接移动云盘

登录网页版后 F12 → 网络 → 任意请求 → 请求头 Authorization，去掉开头的 Basic 空格 后粘贴
留空即可。若使用，需登录 mail.10086.cn 后复制完整 Cookie（含 Os_SSo_Sid 与 RMKEY）

2. 生成 STRM

该目录需要同时挂载给 Emby / Jellyfin，两边路径保持一致
Emby 将通过此地址访问本项目，必须是播放器能连通的地址
.cas 只有几百字节，是真实文件的"特征码"。勾选后照常生成 strm，播放时服务端会临时秒传还原出真文件再跳转，播完自动删掉临时文件。
增量：同名 strm 已存在就跳过，只补新的；强同步：全部重新生成（覆盖旧文件）。
仅清理本次同步范围内、源头已不存在的 .strm；绝不删字幕 / 图片等附属文件，也不会动其他来源的 strm。建议与「强同步」搭配使用。

CAS 秒传播放

播放器拿到 302 后才会真正开始拉流，所以要预留一点时间再删临时文件。拖动进度条不会重复还原（直链已缓存）。

定时同步

开启后按设定周期自动扫描云盘目录、生成 / 更新 STRM，无需手动点。增量模式只补新文件，强同步模式覆盖重生成。
:
定时任务无网页请求上下文，必须先在「连接移动云盘」里填好「访问地址(base_url)」，否则会跳过本次运行。

4. 选择要生成的目录 点击文件夹进入，选好后点「用这个目录」

使用说明

  1. 填入 Authorization 并测试连接
  2. 设置输出目录（需与 Emby 挂载同一个目录）
  3. 生成 STRM，等待任务完成
  4. Emby 添加媒体库，扫描该目录即可入库
  5. 播放时 Emby 请求本项目 /d/ 地址，服务端 302 跳到移动云盘直链，视频流不经过本机
